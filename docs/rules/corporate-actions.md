# 公司行为政策

登记日收盘先锁定持股权益，不增加现金/应收；除息时记应收，派息时转为现金。bar 使用原始不复权价，不二次扣价。除息尚无新 bar 时，估值保留旧价并标 stale，不借未来价格修正。
送转新增权益在除权时加入 pending lot，现存总成本在旧批次和新权益间按份额分配，最后残差保留旧批次；到上市日只解除 pending，不增发第二遍。零碎政策缺失时阻塞。
除权/退出时取消相关未完成订单，保护价不自动改写。明确的普通退出 game-writeoff-v1 归档残余批次并记游戏核销损失，已登记现金权益仍照期支付。
RIGHTS/ACQUISITION/EXCHANGE 在生效前阻塞，绝不进入普通归零分支。未知价格为 null/UNKNOWN_PRICE，可靠旧价标 stale。
